# PhaseCraft Trainer, Android edition

A phone friendly version of PhaseCraft, built for students to practice on their own
devices. It has two modes:

- **Practice**: generates a random set of "measured" readings for one of the three
  subtasks and asks the student to decide Pass or Fail. It then reveals the correct
  answer, the calculation behind it, and a short explanation. Score is tracked on
  screen and can be reset at any time. A fresh random scenario loads with a tap of
  "Next scenario".
- **Checker**: the same three subtask calculators from the desktop app (winding
  resistance tolerance, Star-Delta line voltage balance, Star-Star line, phase and
  root three checks), laid out for a touchscreen, so a student can type in their own
  real workshop readings and see the same Pass or Fail logic a lecturer would apply.

The app works fully offline. There is no PDF export and no login, it is meant purely
for self practice.

## Download a ready made APK

A ready made `PhaseCraft-Trainer-x.y.z-debug.apk` is attached to every release on the
[Releases page](https://github.com/Manofork/phasecraft-pat2/releases/latest). Copy it to the phone and
open it. Android will ask you to allow installation from unknown sources (from your browser or file
manager) the first time. The APK is signed with a debug key that changes between releases, so
uninstall any older version of PhaseCraft before installing a newer one.

## What is in this folder

- `www/index.html`, the entire app (one file, no external files or internet
  connection required).
- `android/`, the native Android project generated by Capacitor.
- `resources/icon.png`, the source app icon.
- `package.json`, `capacitor.config.json`, project configuration.
- `open-in-android-studio.bat`, a one click setup script for Windows.

## Building the app (do this once per computer)

You need two free tools installed first:

1. **Node.js** (LTS version), from https://nodejs.org
2. **Android Studio**, from https://developer.android.com/studio

Then double click `open-in-android-studio.bat` in this folder. It will:

1. Install the project's build tools (`npm install`).
2. Copy the web app into the native Android project (`cap sync`).
3. Open the project in Android Studio.

The first time Android Studio opens the project it will run "Gradle sync", which can
take a few minutes and needs an internet connection to download Android build tools.
Let it finish (watch the progress bar at the bottom of the window).

### Building from a fresh clone

A fresh clone of the repository does not contain the generated parts of the native project
(`android/capacitor-cordova-android-plugins` and the copied web assets). Generate them before any
Gradle build:

```bash
cd android-app
npm ci
npx cap sync android
```

Then build in Android Studio as described below, or from the command line in `android-app/android`
with `./gradlew assembleDebug` (`gradlew.bat assembleDebug` on Windows) using JDK 21. Keep the project
outside OneDrive or other synced folders, since syncing can corrupt `node_modules`.

## Producing an installable file for students

Once Gradle sync is finished, in Android Studio:

- **Menu bar** &rarr; `Build` &rarr; `Build Bundle(s) / APK(s)` &rarr; `Build APK(s)`
- When it finishes, click the "locate" link in the notification, or find the file at
  `android/app/build/outputs/apk/debug/app-debug.apk`

That `.apk` file is what you share with students (WhatsApp, Google Drive, USB, etc).
Android will ask them to allow "install from unknown sources" the first time, since
this is not distributed through the Play Store.

For a more polished release build (smaller file, no debug banner), use
`Build` &rarr; `Generate Signed Bundle / APK` instead, and follow Android Studio's
prompts to create a signing key. Keep that signing key file somewhere safe. You will
need the same one for every future update of the app.

## Making changes later

If you edit `www/index.html` (wording, colours, new practice scenarios, and so on),
run `open-in-android-studio.bat` again before rebuilding in Android Studio. That
script re-copies your changes into the native project; Android Studio will not see
edits to `www/index.html` until `cap sync` has run.

## Notes

- If `npm install` ever behaves oddly, it is safe to delete the `node_modules` folder
  in this directory in File Explorer and run `open-in-android-studio.bat` again.
- The Practice mode generates readings with realistic random variation each time, so
  no two students will see exactly the same numbers.
