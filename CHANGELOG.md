## [1.0.0] - 2026-10-04

### Added
- Windows desktop application for lecturers (installer and portable builds): three subtasks, 5 % tolerance logic,
  colour coded results, acceptable ranges, overall verdicts, native vector PDF report, developer tools disabled.
- Android trainer application for students: Practice mode (random scenarios, Pass or Fail, explanation, score) and
  Checker mode (the three calculators), fully offline.
- GitHub repository with CI, automated releases (installer, portable, Android debug APK, checksums), CodeQL and
  Dependabot.
